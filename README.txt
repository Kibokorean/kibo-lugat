KIBO Lug'at — Vercel/GitHub deployment

1. Extract this ZIP.
2. Upload index.html to the root of https://github.com/Kibokorean/kibo-lugat
3. Commit the change, replacing the empty index.html.
4. Vercel should redeploy automatically.

This package contains the original uploaded HTML renamed to index.html. It does not yet add cloud sync, authentication, or Telegram Mini App integration.
